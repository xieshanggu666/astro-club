# 星野日志 · 天文社团观测计划与记录应用

面向小型天文社团的观测活动管理工具。**零依赖**，只需 Python 3，数据保存在本地 SQLite。

## 运行

```bash
cd astro-club
python3 app.py          # 默认端口 8000，可 python3 app.py 8080 换端口
```

浏览器打开 http://localhost:8000 。首次启动会自动写入示例数据（设备、目标、两次历史活动及记录、一次待排程的活动），便于直接体验；删除 `astro.db` 即可重置。

## 功能

| 页签 | 说明 |
|------|------|
| 观测计划 | 创建活动，填写当晚可用时段、月相、天气记录；添加目标后按出现时间**自动排序**，可随时手动微调 |
| 观测记录 | 按计划条目记录实际开始/结束时间、极限星等、透明度、视宁度、滤镜、曝光参数（ISO/快门/帧数/增益）和文字感受；照片为可选附件 |
| 观测日志 | 按目标整理全部历史记录，同一目标不同日期的记录以**对比表**并排展示 |
| 目标库 | 维护目标的高度、预计出现窗口、月光敏感度、所需设备 |
| 设备 | 维护社团设备清单 |

## 自动检查（计划页实时提示）

- **时段合适性**：计划时间是否落在当晚可用时段与目标预计出现窗口内
- **月光影响**：按目标敏感度与月相照明百分比、月亮在天时段提示
- **天气记录**：透明度差 → 提示深空目标改期；视宁度差 → 提示行星/双星高倍受限；云量高 → 提示准备备选目标
- **设备冲突**：同一设备被重叠时段的两个目标占用时报警
- **目标同时出现**：计划时段互相重叠时提示错开

## 目录结构

```
astro-club/
├── app.py        # HTTP 服务 + REST API（标准库实现）
├── db.py         # SQLite 建表与连接
├── logic.py      # 夜间时间换算、适宜性分析、冲突检测、自动排序
├── seed.py       # 示例数据（仅首次运行写入）
├── static/       # 前端单页应用（原生 JS，无构建步骤）
├── uploads/      # 观测照片附件
└── astro.db      # SQLite 数据库（运行时生成）
```

## 说明

- 时间按"夜间约定"处理：中午 12 点前的时间视为次日凌晨，跨午夜时段可直接比较。
- 照片通过原始字节上传（`POST /api/records/<id>/photos?name=xxx.jpg`），单张限 25MB。
- 多人共用：在一台电脑上运行后，同一局域网成员访问 `http://<主机IP>:8000` 即可。
